# Photos — drop Isaac's real images here

The site is built around **real photo slots**. Until a file below exists, that
spot shows a tasteful deep-blue (or coral) fallback panel with a small filename
hint — nothing looks broken. The moment you add a correctly-named file here, it
appears automatically. No code changes needed.

Use landscape JPGs unless noted. Compress to keep each file under ~400 KB
(e.g. squoosh.app) so pages stay fast.

| Filename | Used on | Shot idea | Min size |
|---|---|---|---|
| `hero.jpg` | Home hero (full-screen) | The money shot — a bright home or storefront with gleaming windows, ideally Isaac at work. Leave the **left side** relatively uncluttered so the headline reads clearly. | 2400×1400 |
| `why-clean.jpg` | Home — "Why" section | Close-up of a flawless, streak-free pane / a clear reflection. | 1400×1120 |
| `service-area.jpg` | Home + Regina page | Isaac or the vehicle heading to a job; a Regina street/home. | 1400×1120 |
| `residential.jpg` | Residential page | Big, bright windows on a Regina family home. | 1400×1120 |
| `commercial.jpg` | Commercial page | A clean, welcoming storefront or office glass. | 1400×1120 |
| `eavestrough.jpg` | Eavestrough page | Clean eavestroughs / the clear-out in progress. | 1400×1120 |
| `method.jpg` | Services page | Hands-on shot: squeegee on glass, the professional finish. | 1400×1120 |
| `isaac.jpg` | About page (portrait) | A friendly photo of Isaac — smiling, approachable. | 1200×1500 |

Tips for good photos (phone is fine):
- Shoot in daylight, wipe the lens, hold steady.
- Landscape (sideways) for everything except `isaac.jpg` (portrait).
- Real > perfect. Genuine job photos build far more trust than stock.
- Bonus: keep a few extra before/after shots for Google Business Profile and social.
